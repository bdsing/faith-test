# 교파별 근거 요약

문항별 교파 기준값을 정할 때 쓴 자료를 요약했습니다. 웹사이트 배포본(`dist`)에는 들어가지 않습니다.

- `sources/<교파>/doctrinal-and-liturgical-corpus-v17.md`: 문항 ID별 기준값(`0`–`1`, 확정하지 않은 항목은 `null`)과 직접 쓴 요약, 출처 ID.
- `sources/<교파>/source-register.json`: 출처 ID별 문헌 이름, 공식 URL, 확인 상태.

교단 헌법 PDF, OCR, 웹 수집 본문 같은 원문은 재배포 권한을 확인하지 않았기 때문에 이 공개 저장소에 넣지 않았습니다. 원문은 비공개 저장소에 따로 보관합니다. 요약은 문항 채점을 위해 정리한 내용일 뿐, 각 교단의 공식 입장문이 아닙니다.
