# 나의 신앙 지도

한국어 기독교 신앙 성향 테스트입니다. 31개 문항을 다섯 영역으로 나누어 응답하고, 결과에서 가장 가까운 교파와 Top 3, 교파별 설명, 영역별 차트, 문항 비교를 확인할 수 있습니다. 정적 파일만으로 동작하며 점수는 브라우저 안에서 계산합니다.

## 로컬 확인

Node.js 20 이상에서:

```sh
npm run check    # v18 데이터·채점 테스트와 배포 파일 검증
npm run dev      # 로컬 미리보기
npm run release  # 버전별 배포 스냅샷 생성
```

미리보기 기본 주소는 `http://localhost:4173`입니다. 추가 패키지 설치가 필요하지 않습니다.

## 수정과 배포

- 앱 원본: `faith-map-v18/`
- 질문·배점·교파별 비교 기준: `faith-map-v18/data.js` (공개 정적 사이트의 브라우저 채점에 사용)
- 비교 공식: `faith-map-v18/score.js`
- 화면 동작·표현: `faith-map-v18/app.js`, `index.html`, `styles.css`
- 성인·신학자 후보: `faith-map-v18/people.js` (11개 교파 × 4명)
- 응답 공유 링크 인코더: `faith-map-v18/share.js`
- 정적 사이트 산출물: `dist/`

빌드는 공개 파일 허용 목록만 `dist/`로 복사합니다. 정적 호스팅에서 채점하기 위해 문항·배점·교파별 비교 기준·채점 공식·설명·인물 소개가 공개 파일에 포함됩니다. 응답은 서버로 전송되지 않고 브라우저에서 계산되며 저장되지 않습니다. 조사 기록, 문헌 검토 자료와 OCR 자료는 정적 산출물에 포함하지 않습니다.

GitHub Actions는 `main`에 변경이 올라오면 검사와 빌드를 실행하고 GitHub Pages에 배포합니다. 공개 저장소에는 사이트 전용 앱과 빌드·검사 파일만 포함하며, 연구·OCR 원본 자료와 이전 버전은 포함하지 않습니다. 상세 상태는 `HOSTING.md`를 참고하세요.

## v18 비교 기준과 한계

- 문항 31개, 교파 11개, 영역 5개(20·27·21·20·12점), 응답값 `0`, `0.25`, `0.50`, `0.75`, `1.00`을 사용합니다. `0.50`은 중립 응답이며, `잘 모르겠음`과 `둘 다 내 생각과 다름`은 별도 응답으로 기록하고 점수에서 제외합니다.
- 문항별 기준점·범위에서의 거리를 `1 - d^1.35`로 바꾸고, 문항별로 달성 가능한 최고값으로 정규화한 뒤 답변한 배점으로 가중 평균합니다. 부분 답변도 비교할 수 있으며, 점수는 확률이나 객관적 적합도가 아닙니다.
- 신앙 좌표 지도는 가운데 교점을 두 축의 절대 0점으로 두고, 응답과 교파별 문항 기준의 방향 평균을 같은 좌표에 표시합니다. 5점 척도의 중립 응답은 해당 축에서 0을 뜻하며, 교파 점수 자체가 0점이라는 뜻은 아닙니다. 축과 좌표는 공식 분류나 권위 있는 신학 판정이 아닙니다.
- 응답은 브라우저 안에서 계산되며 서버로 전송되거나 저장되지 않습니다. 닉네임과 현재 소속 교파도 브라우저 안에서만 사용합니다. 공유 링크는 31개 응답을 압축해 URL에 담으므로, 링크를 받은 사람이 결과를 열람할 수 있습니다. 익명 결과 통계 저장 기능은 구현하지 않았습니다.
- 교파별 설명과 인물 추천은 평신도용 요약입니다. 한국 장로교의 통합권·합동권 표기는 여러 교단을 아우르는 흐름이며, 세부 교단의 입장에는 차이가 있습니다.

이전 버전의 산출물과 조사 자료는 배포 입력으로 사용하지 않습니다.
